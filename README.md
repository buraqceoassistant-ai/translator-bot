# Translator Bot — переводчик для рабочих Telegram-групп

Google Translate для простых сообщений, Claude Haiku с глоссарием компании — для сложных
(термины, цифры с единицами, длинные тексты, смешанные языки). Если один сервис упал — переводит другой.

## Запуск за 5 минут

1. Создать бота в @BotFather → скопировать токен.
2. В @BotFather: `/mybots` → бот → **Bot Settings → Group Privacy → Turn off**
   (иначе бот не видит обычные сообщения в группе).
3. ```bash
   cd translator-bot
   python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env     # вписать BOT_TOKEN (остальное опционально)
   python bot.py
   ```
4. Добавить бота в группу. По умолчанию группа работает как 🇨🇳 ↔ 🇷🇺.
   Поменять: `/lang zh ru uz` (пишет админ группы).

## Как решает, чем переводить

| Сообщение | Движок |
|---|---|
| обычный короткий текст | Google |
| длиннее 250 символов | Haiku ✨ |
| есть числа с единицами (кг, cbm, $, 元, дней…) | Haiku ✨ |
| смешаны алфавиты (китайский + латиница и т.п.) | Haiku ✨ |
| содержит термин из `glossary.json` | Haiku ✨ |
| ответ `/pro` на сообщение | Haiku ✨ принудительно |
| кнопка «🔁 Точнее (ИИ)» под переводом Google | Haiku ✨, бот редактирует свой ответ |
| Google недоступен | Haiku; Haiku недоступен → Google |

Перевод через Haiku помечается ✨ в конце.

## Перевод по фото

Накладные, инвойсы, этикетки, скриншоты переписки — бот распознаёт текст и переводит.

| Где | Когда переводит |
|---|---|
| личка с ботом | любое фото с текстом — сразу |
| группа | ответ `/pro` на фото, или фото с подписью «перевод» / «翻译» / «tarjima» |
| группа, `AUTO_PHOTO=1` | все фото автоматически |

Ответ: распознанный оригинал в свёрнутой цитате + перевод на остальные языки группы.

Движок: **Haiku (vision)** — один запрос делает OCR и перевод с учётом глоссария.
Запасной путь, если Haiku недоступен: **Google Cloud Vision OCR → Google Translate**
(нужно включить Vision API в том же проекте Google Cloud; первые 1000 изображений в месяц бесплатно).

Поддерживаются сжатые фото и картинки, отправленные файлом (jpg/png/webp). PDF — пока нет.

## Глоссарий

`glossary.json` — термины компании на 4 языках. Haiku получает их как обязательные соответствия.
Добавляйте строки по образцу, перезапуск бота обязателен (файл читается при старте).

## Личный режим

Сотрудник пишет боту в личку текст на русском — бот отвечает китайским (и наоборот).
Удобно, когда бота нельзя добавить в группу поставщика. Языки для лички тоже меняются через `/lang`.

## Ключи

- **GOOGLE_API_KEY** — Cloud Translation API, ~$20 за 1 млн символов, первые 500 тыс. символов в месяц бесплатно.
  Без ключа работает `deep-translator` (неофициально, бесплатно) — ок для теста, для прода лучше ключ.
- **ANTHROPIC_API_KEY** — Haiku, примерно $0.001–0.003 за сообщение. Без ключа всё идёт через Google.

## Деплой на Railway

В проекте уже есть `Procfile` (`worker: python bot.py`) и `.python-version` — Railway соберёт его сам.

1. Залить папку в GitHub-репозиторий (без `.env` — он в `.gitignore`).
2. railway.com → **New Project → Deploy from GitHub repo** → выбрать репозиторий.
3. В сервисе → **Variables** → добавить:
   - `BOT_TOKEN`
   - `ANTHROPIC_API_KEY` (для Haiku и фото)
   - `GOOGLE_API_KEY` (опционально)
   - `DEFAULT_LANGS=zh,ru`, `AUTO_PHOTO=0` (по желанию)
4. В сервисе → **Settings → Volumes → Add Volume**, mount path `/data`.
   Бот сам увидит `RAILWAY_VOLUME_MOUNT_PATH` и будет хранить там `chats.json` и `glossary.json`.
   Без Volume настройки групп сбрасываются при каждом деплое.
5. **Settings → Networking**: публичный домен не нужен — бот работает через long polling.
6. Deploy. В логах должно появиться `Bot started. Data dir: /data …`.

Альтернатива без GitHub — Railway CLI с компьютера: в папке проекта `railway up`
(сам предложит войти и создаст проект), затем переменные и Volume — как выше.

При каждом редеплое на несколько секунд живут две копии бота — Telegram может написать в лог
`Conflict: terminated by other getUpdates request`. Это нормально, проходит само, когда старая копия гаснет.

Чтобы отредактировать глоссарий на Railway: после первого запуска он лежит на Volume, не в репозитории.
Проще всего пока — поменять `glossary.json` в репо, удалить файл на Volume (через `railway ssh`) и редеплоить.
Команда `/add` для правки из чата — в планах.

### Другие хостинги

Любой VPS / Render / Docker: `python bot.py` в фоне. Укажите `DATA_DIR=/путь/к/постоянной/папке`.
